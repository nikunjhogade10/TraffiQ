Create the second screen for the TRAFFIQ mobile app: “Select Gate and Traffic View”.

This screen opens after Login or Continue as Guest.

Use the same visual design system as the login screen: 390 × 844 mobile frame, light background, dark navy typography, cyan/teal primary accent, rounded cards, and clear hierarchy.

Screen content:
- Top app bar with back arrow and title: “Choose a Gate”
- Supporting text: “Select a campus gate to view live traffic.”
- A dropdown field labeled “Select Gate”
- Default dropdown value: “Main Campus Gate”
- Dropdown options:
  1. Main Campus Gate
  2. North Gate — Coming Soon
  3. South Gate — Coming Soon
  4. Hostel Gate — Coming Soon
- Disable future gates but keep them visible
- Add a large traffic summary card for the selected gate:
  - Gate name: “Main Campus Gate”
  - Current status: “Heavy Traffic”
  - Number of vehicles detected: “26 vehicles”
  - Vehicle activity: “High”
  - Last updated: “1 minute ago”
- Add three small statistic cards:
  - “Vehicles: 26”
  - “Queue: Long”
  - “Rain: Detected”
- Add a primary button: “View Gate Traffic”
- Add a secondary text link: “View All Gates”

Interactions:
- Tapping the dropdown opens an overlay menu.
- Selecting “Main Campus Gate” updates the summary card.
- Tapping “View Gate Traffic” opens the Home Dashboard.
- Tapping “View All Gates” opens a gate comparison screen.
- If a future gate is selected, show: “This gate will be available in a future update.”
- Keep the number of detected vehicles prominent, but label it as sensor-estimated rather than exact camera counting.

- “Rain detected”
- “College bus movement detected”

- “Recommendation: Wait before leaving”
